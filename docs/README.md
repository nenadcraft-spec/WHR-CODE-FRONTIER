## Redosled odluka

Ekonomija daje osnovu, a Tier dokumenti je preciziraju. T2 definiše Tier kao nivo celog igrača. T3 dodaje protivvazdušni napad Strelcu i kuli već na T2. Jungle MASTER zamenjuje T1 pravilo bez respawn-a i precizira garantovane predmete samo pri prvom čišćenju.

Sve brojke su kandidati za balans. Specifikacija cele igre ne znači da sve funkcije već rade u prototipu. OPEN stavke zahtevaju odluku pre odgovarajuće implementacije.

## Razvoj

Prvi lokalni korak: mapa, kamera, selekcija, radnici, CODE, proizvodnja i Scout. Slede gradnja/borba, džungla/heroji i inventar, T2/T3, pa autoritativni multiplayer i lobi. Koncept slike tek treba dodati kao stvarne grafičke asset fajlove. GitHub Pages služi klijent, ne zamenjuje multiplayer server.
